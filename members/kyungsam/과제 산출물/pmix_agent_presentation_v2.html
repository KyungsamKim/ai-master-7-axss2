Ch 0. Introduction

P-Mix 수익성 Simulation Agent

자연어 질의로 P-Mix 수익성을 분석하고, 변수 조정에 따른 수익성 변화를 즉시 정확하게 계산하며 인사이트를 제공합니다.
Validation
최신 생성 계획 버전의 수율과 원가 누락치 Validation 해줘.
Analysis
경영계획 대비 6RP 버전 장당 영업이익과 EQ 판매수량 비교 분석해줘.
Simulation
7월 확정 버전 SP 16G DDR5 제품을 LC 16G DDR 제품으로 Mix 전환했을 때 수익성 변화를 알려줘.

Ch 2. 구현

[Back-Up] Agent 주요 기능 레이어

1
Orchestrator
사용자의 자연어 요청을 정규화하고, 적절한 기능 Layer로 라우팅하며 flow를 제어함
주요 기능 : 요청 해석 및 구조화, Flow 라우팅, 필수 파라미터 체크, 결과 값 출력
2
Validation
수익성 Plan Ver Data의 이상치를 식별하고 누락치 조정 결과를 해석함
주요 기능 : 누락치 요약, 누락치 입력 프로시저 Call
3
Analysis
수익성 Plan Ver Data의 다각적 분석을 수행하기 위해 Data를 연산하고 요약함
주요 기능 : 월별 트렌드 분석, Mix 분석, Ver간 비교 분석, 원인 분석
4
Simulation
사용자가 수익성 Data의 변수를 조정하여 기준 Plan Ver 대비 수익성 변화를 산출함
주요 기능 : QTY(Mix) Simulation, ASP Simulation, 수율 Simulation
5
Case 생성
담당자가 설정한 제약 조건 하에서 최적의 P-Mix Case를 탐색해 제안함
주요 기능 : 제약 조건 정의, 후보 Case 생성 및 평가, 최적안 추천
6
Data Retrieval
각 기능 Layer가 필요로 하는 데이터를 표준화된 방식으로 조회해 전달함
주요 기능 : Ontology 참조, 수익성 Data IF, 프로시저 Call
Ch 2. 구현

Agent 차별성

1
Ontology
LLM의 판단 기준을 코드 밖으로
  • 하이닉스 반도체 제품군과 수익성 지표를 객체화·구조화
  • 제품의 의미와 수익성 연산식을 Agent가 이해
2
집계 처리 엔진
  • Agent Layer와 MCP 집계 처리 엔진 역할 분리
  • 계산은 LLM 없이 집계 처리 엔진이 담당
  • 100% 계산 결과를 신속하게 처리
3
데이터 보안 체계 준수
  • Agent Layer는 DB에 접근 불가
  • 하이닉스 표준 보안 준수
  • Workflow 개발 Tool 준수
